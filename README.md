# UAV Mission Dashboard (Mini)
เว็บแอปพลิเคชันสำหรับดูและจัดการข้อมูลของรายการภารกิจการบินของอากาศยานไร้คนขับ

# DEMO Link
https://youtu.be/0fOOXDJpzt4

## พัฒนาด้วย
- **Next.js (App Router)**
- **React**
- **TypeScript**

## สิ่งที่ต้องเตรียมก่อนเริ่ม
- **Node.js** (แนะนำเวอร์ชัน 18.18 หรือ 20+ ขึ้นไป)
- **npm** (มาพร้อมกับ Node.js)

## วิธีการติดตั้งและรันโปรเจกต์

1. ดึงโปรเจกต์ลงเครื่อง (กรณีดึงจาก repository)
    ```bash
    git clone https://github.com/Pimpisa2546/uav-mission-dashboard-mini.git
    ```
2. เข้าสู่โฟลเดอร์โปรเจกต์
    ```bash
    cd uav-mission-dashboard-mini
    ```
3. ติดตั้ง dependencies
    ```bash
    npm install
    ```

4. รันเซิร์ฟเวอร์
    ```bash
    npm run dev 
    ```
